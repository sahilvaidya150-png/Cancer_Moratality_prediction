# 🩺 Cancer Mortality Rate Prediction

## 📌 Project Overview

This project analyzes cancer-related data and predicts **cancer death rate (`TARGET_deathRate`)** using Machine Learning.

## 📊 Dataset

- **Dataset:** `cancer_reg.csv`
- **Rows:** 3,047
- **Target:** `TARGET_deathRate`

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🔍 Project Steps

1. Data Loading
2. Data Cleaning
3. Missing Value Handling
4. Outlier Detection
5. Correlation Analysis
6. Feature Selection
7. Train-Test Split
8. Linear Regression
9. Polynomial Regression
10. Model Evaluation
11. Data Visualization

## 🤖 Machine Learning Models

- Linear Regression
- Polynomial Regression (Degree 2)
- Polynomial Regression (Degree 3)

## 📈 Evaluation Metrics

- MAE
- MSE
- RMSE
- R² Score
